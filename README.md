# BMI Roast Machine 💀

The world's most brutally honest BMI calculator. Enter your weight and height — get destroyed.

🔗 **Live:** [demoslady.github.io/bmi-roast-machine](https://demoslady.github.io/bmi-roast-machine/)

## Features
- Metric (kg/cm) & Imperial (lbs/ft) toggle
- Category-specific savage insults (underweight, normal, overweight, obese)
- 🎲 "Insult Me Again" reroll button
- Share to X (Twitter), WhatsApp, or copy to clipboard
- Glitch effects, screen shake, scanline overlay
- Mobile responsive
- SEO optimized with Open Graph & Twitter Cards
- AdSense ready

## Deployment
This is a single `index.html` file. Just push to GitHub and enable Pages.

## AdSense Setup
1. Get approved at [Google AdSense](https://www.google.com/adsense/)
2. Replace `ca-pub-XXXXXXXXXXXXXXXX` in `index.html` with your publisher ID
3. Uncomment the `<ins class="adsbygoogle">` blocks for manual ad units
4. Or just use AdSense auto-ads (recommended — it places ads automatically)
